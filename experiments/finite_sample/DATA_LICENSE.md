# Dataset attribution

Wisconsin Diagnostic Breast Cancer dataset, obtained from the packaged `sklearn.datasets.load_breast_cancer` copy. The archive contains a fixed train/test split and transformed features derived from this dataset; transformations standardize using the training pool, append an intercept and normalize each feature row. Split indices and raw-data hashes identify the inputs.

UCI citation: Wolberg, W., Mangasarian, O., Street, N., & Street, W. (1993). Breast Cancer Wisconsin (Diagnostic) [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5DW2B . UCI lists donation in 1995 but its dataset citation year is 1993.
