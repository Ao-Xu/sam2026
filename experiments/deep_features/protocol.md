# Frozen deep-feature experiment protocol

The experiment protocol was fixed before downloading features or inspecting outcomes. Theory files remain unchanged.

Models: torchvision ResNet18 IMAGENET1K_V1 (512-dimensional penultimate features) and ViT-B/16 IMAGENET1K_V1 (768-dimensional class-token features), evaluation mode, official weight-specific deterministic preprocessing, float32 GPU inference. Normalize each extracted feature row to unit Euclidean norm; no PCA truncation or fitted representation. No free intercept is added. Cache model outputs and dataset indices with hashes. Backbone weights are frozen throughout.

Dataset: official CIFAR-10 train/test split. Using NumPy seed 9142026, choose 300 training and 100 test images per class without replacement, concatenate and sort indices. This is a fixed image pool, not a claim of representativeness for all CIFAR images. Use all 3000 training-pool images for the discrete weak-signal population objective. Select 2048 of these images without replacement, seed 9142027, for conditional balanced-label sampling. Test images are never used to select features, probes or hyperparameters.

Ridge .02; radii 0,.25,.5,1. These are fixed design choices, not fitted to response outcomes. Retain all directions corresponding to eigenvalue ranks 1,8,32 (descending) in the full normalized feature covariance. Select these before labels; reject only a zero/unobservable eigenvalue with a logged reason. Weak-signal labels have mean epsilon*q with epsilon=.05,.1,.2, q equal to each feature eigencoordinate divided by its maximum absolute value on the fixed pool. Independently optimize the exact expected shifted-logistic objective by summing over the two labels with their known probabilities. Compare vector predictions and coordinate gains to the existing linear-response operator. This uses a finite discrete input distribution of real images and introduces no new theorem.

Balanced labels: 100 independent Rademacher label vectors, seed 9142100, shared across radii. Independently optimize the exact per-example shifted-logistic objective plus external ridge. Report n-scaled second moments in the three fixed conditional-design eigendirections (ranks1,8,32), conditional-linearized analytic covariance, and the realized paired linearized second moments. Label symmetry implies zero mean; report ordinary centered variance as an auxiliary diagnostic. Pointwise paired-repeat bootstrap intervals use 2000 draws, seed9142200. Ratios are not unbiased covariance estimators. This holds inputs fixed, so it does not test random-input design error. Compare realized linearized and exact fits to separate nonlinear bias from label Monte Carlo fluctuation.

Real labels: predefined pairs cat/dog (3,5), automobile/truck (1,9), airplane/ship (0,8). Each has 600 training-pool images and 200 untouched test images. Thirty bootstrap training samples per pair, seed9142300+pair_index, shared across all radii. Ridge remains .02. Report unperturbed test logistic loss, accuracy and centered across-bootstrap prediction-score variance. This is a fixed-ridge mechanism comparison, not a tuned performance ranking; no claim of superiority to tuned ERM or shared SAM. Do not infer balanced-label results from true labels. No shared-SAM or Functional-SAM implementation is substituted by shifted logistic loss.

All head fits use the exact objective in float64, converged gradient norm <=1e-9 where possible (hard acceptance <=1e-8). Use batched strongly-convex accelerated gradient with full feature covariance Lipschitz bound, then ordinary gradient polish; failed convergence must be repaired without changing experimental settings. Verify selected outputs with an independent SciPy L-BFGS optimizer and finite-difference gradient checks. GPU model batch size may be adjusted solely for memory/throughput. Smoke runs validate implementation only and are not publication evidence.

Publication plan: one figure comparing predicted and observed signal/noise gains for both backbones, plus one real-label table. Report every declared radius/probe/task, including disagreement. No outcome-dependent stopping, seed screening, backbone replacement or model selection. Feature computation can resume by cache; fit groups and raw outputs are checkpointed. Feature hashes and package versions are retained; machine-specific runtimes are omitted from this release. Only code failures justify reruns; any such fixes are logged.
